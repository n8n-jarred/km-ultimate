# KM Ultimate — Beginner's Playbook 🥏

An interactive beginner's guide to ultimate frisbee by **Kid Mafia Ultimate · Laguna**.
Covers rules, backhand & forehand throws, catching, on-field roles, and Spirit of the Game.

**Live site:** https://YOUR-USERNAME.github.io/km-ultimate/  ← update after publishing

## Publishing (GitHub Pages)
1. Create a repo named `km-ultimate`
2. Upload `index.html` to the `main` branch
3. Settings → Pages → Source: `main` → Save
4. Site goes live at `https://YOUR-USERNAME.github.io/km-ultimate/`

## Stack
Single-file HTML/CSS/JS — no build step, no dependencies.
